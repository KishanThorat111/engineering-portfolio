# DESIGN REFERENCE SYSTEM

These ten images are the approved visual references for the redesign.

They are not background images.

They are visual specifications.

The implementation must reconstruct their visual world using the
appropriate combination of:

- HTML
- CSS
- SVG
- Canvas
- Three.js/WebGL/WebGPU
- real API data
- animation
- interaction
- image assets

The final implementation must preserve the visual intent of the
references while making the experience interactive and responsive.

The images are numbered according to narrative order.

01 — ENTER
02 — SYSTEMS
03 — DISSECTION
04 — DATA
05 — LAB
06 — LIVE
07 — THINK
08 — BUILD
09 — PROOF
10 — END

Image 11 SYSTEM MAP is intentionally excluded from this phase.
It will be designed after the first ten experiences are implemented
and evaluated.
